# Silent Leads Retouch MVP

Офлайн-інструмент, який обробляє контрольну вигрузку silent-лідів з CRM, перевіряє строк першого
повторного касання, аналізує історію спілкування і формує рішення для перевірки людиною.
Реальні повідомлення не надсилаються, до CRM нічого не підключається, дані нікуди не передаються.

- Що будуємо і навіщо — [PRODUCT.md](PRODUCT.md)
- Як будуємо (стек, правила, команди) — [CLAUDE.md](CLAUDE.md)

## Швидкий старт

Потрібні Python 3.12+ і [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

Покладіть вигрузку (Google Sheets → Файл → Завантажити → .xlsx) у `data/input/export.xlsx`.
Папка `data/` не комітиться.

```bash
uv run python -m silent_leads.cli validate --input data/input/export.xlsx --config config.example.yaml
```

Команда читає вкладки «Ліди», «Повідомлення», «Інструкція», «Контроль», звіряє контрольні суми,
визначає контрольну дату зі знімка і перелічує знайдені проблеми даних. Коди виходу:
`0` — ок, `2` — файл не схожий на вигрузку (немає вкладки/колонки), `3` — контрольні суми не збігаються.

Конфігурація: скопіюйте `config.example.yaml` у `config.yaml` і змініть за потреби. Секретів у конфігу немає.

## Статус

Етап 1 (читання, валідація, хронологія, знімок) готовий і покритий тестами.
Етап 2 (правила рішень, шаблони, вихідний файл і зведення — команда `run`) — наступний.

```bash
uv run python -m pytest
```
