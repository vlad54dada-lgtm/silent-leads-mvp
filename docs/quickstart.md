# Запуск на новій машині: одна сторінка

Потрібні Python 3.12+ і [uv](https://docs.astral.sh/uv/). Версія для демо зафіксована тегом `demo-13-11`.

## 1. Встановлення

```bash
git clone https://github.com/vlad54dada-lgtm/silent-leads-mvp
cd silent-leads-mvp
git checkout demo-13-11
uv sync
```

## 2. Ключ

Скопіюйте `.env.example` у `.env` і впишіть ключ OpenRouter після знака `=`:

```text
OPENROUTER_API_KEY=ваш_ключ
```

Файл `.env` у git не потрапляє. Якщо змінна вже задана в середовищі, береться вона.

## 3. Конфіг

Нічого міняти не треба: `config.demo.yaml` уже налаштований. У ньому політика v2 «Кому пишемо», Claude Sonnet 5.5
через OpenRouter, чернетки SMS і вікно 3 години після silent. Секретів у конфігу немає.

## 4. Команда

Покладіть вигрузку у `data/input/export.xlsx` (папка `data/` не комітиться) і запустіть:

```bash
uv run python -m silent_leads.cli run --input data/input/export.xlsx --config config.demo.yaml --output data/output
```

Наприкінці команда друкує кількість рішень, помилки виклику моделі і час прогону. Заміряно на 150 лідах:
близько 10 хвилин і 2,5 долара; повторний запуск з кешу — 10 секунд.

Кеш. Відповіді моделі зберігаються в `data/ai_cache`, тому повторний запуск нічого не коштує і триває секунди.
У свіжому клоні кешу немає. Щоб оцінити все заново і побачити реальну вартість, видаліть папку `data/ai_cache`
перед запуском. Вартість видно на сторінці Activity в OpenRouter як різницю витрат ключа до і після прогону.

## 5. Де результат

Усе в `data/output/`:

| Файл | Що в ньому |
|---|---|
| `results.xlsx` | Аркуші «Результат» (рішення і причина по кожному ліду), «Мітки», «Чернетки SMS», «Проблеми даних» |
| `results.csv`, `labels.csv`, `drafts.csv` | Те саме для машинної обробки |
| `summary.md` | Зведення: скільки яких рішень, причини ручної перевірки, питання до замовника |

## 6. Метрики проти розмітки

Коли є файл вигрузки із заповненою вкладкою «Розмітка», точність рахує одна команда:

```bash
uv run python -m silent_leads.cli evaluate-policy-labels --input data/input/labeled.xlsx --config config.demo.yaml --labels data/output/labels.csv --output data/output
```

Вона порівнює мітки з `labels.csv` з еталоном у вкладках «Розмітка» і «Приклади» та пише `policy_evaluation.md`:
точність по мітках, матрицю помилок, пропущені й хибні відмови, список розбіжностей.

## Якщо щось не так

- Команда каже, що змінну `OPENROUTER_API_KEY` не задано: перевірте, що `.env` лежить у папці, з якої запускаєте.
- У зведенні є «УВАГА: AI не оцінила частину кейсів»: закінчились кошти або ліміт ключа. Поповніть і запустіть
  ту саму команду ще раз, прогін продовжиться з того ж місця.
- Windows блокує запуск із `.venv`: див. розділ «Windows з Application Control» у [README](../README.md).
